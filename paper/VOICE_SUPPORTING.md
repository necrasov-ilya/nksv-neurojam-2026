# Озвучивание второстепенных персонажей — LATENTPUNK

## Контракт для агента озвучивания

- Это новые реплики продолжения, не замена записанного пролога, города и собеседования. Их текст и ID совпадают с `scripts/campaign/dialogue.gd`; не изменять текст самовольно.
- Один файл на ID. Финальный формат: OGG Vorbis, моно, 48 кГц; чистый голос без музыки, реверберации, радио-фильтра, печатной машинки и длинной тишины. Для реплик по связи эффект не запекать: сначала нужен сухой мастер.
- Ориентир мастерирования: около −16 LUFS, true peak не выше −1 dBTP; не выравнивать отдельные слова до одинаковой громкости. Дыхание естественное, хвост фразы не обрезать.
- Пути: `assets/audio/dialogue/campaign/<персонаж>/<ID>.ogg`. ID уже является именем файла, без пробелов, кириллицы и случайных названий.
- Исходные записи сохранять в `assets/audio/dialogue/campaign/originals/<персонаж>/`; приложить происхождение и условия использования к `assets/SOURCES.md`. Не заменять существующие голоса и не удалять notices.
- Игра автоматически подхватит OGG по указанным путям после импорта Godot. Сейчас новые диалоги реализованы текстом; отсутствие нового голоса не заменяется чужой записью.
- Названия LATENT SYSTEMS и LATENTPUNK произносить так же, как в уже записанном вступлении. DUSTFALL и DEAD PARADE не переводить; выбрать одинаковое произношение во всех дублях.
- В таблицах представлены альтернативные ветки, а не одна последовательная дорожка. Для каждой реплики записать обычный дубль; альтернативный дубль допускается отдельно, не вместо основного.

## Не озвучивать этим пакетом

Исходных NPC города и терминал собеседования; голоса внутри импортированных игр; письменные письма и статусы сайта. Новые персонажи говорят только реплики с ID из таблиц. Отдельного диктора, скрытого антагониста или реплик «это всё ещё испытание» нет.
