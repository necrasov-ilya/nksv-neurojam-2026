# LATENTPUNK: TEST SUBJECT 0

**«Мы тестируем реальность. Реальность тестирует вас».**

Короткий научно-фантастический психологический хоррор о тестировщике LATENT SYSTEMS. Независимые модели генерируют одинаковые аномалии; решения в отчётах меняют последующие испытания и саму лабораторию. Найденные ошибки должны стать инструментами против системы.

Проект для Гейм джема Цифрового колледжа **«72 часа»**, 9–12 октября 2026, тема **`****-ПАНК`**. Первая цель — цельный атмосферный игровой цикл. Конкретные механики и количество миров могут измениться.

## Состояние

- Сохранён технический шаблон Godot 4.7.2 Standard, GDScript, Compatibility, однопоточный Web-экспорт; стартовая сцена — `scenes/start.tscn`.
- Реализовано спокойное вступление от городской остановки до кабинета 1406: населённый квартал, холл, администратор, лифт и экран регистрации LATENT SYSTEMS. Управление — WASD, мышь, E; Esc — пауза, повторный запуск и меню. Устройство сцены, экспорт и проверки описаны в [paper/PIPELINES.md](paper/PIPELINES.md#вступление-latentpunk).
- В `games/` собраны исходные проекты и готовые сборки независимых браузерных игр. Их тип поставки, происхождение, лицензии и команды запуска — в [paper/SOURCES.md](paper/SOURCES.md). Существующие исходники сохранены; для новых импортов достаточно работающей сборки.
- Лаборатория, сквозные аномалии и общий контракт испытаний пока не реализованы. Перенесённые миры запускаются отдельно, не через стартовый экран Godot.
- Архитектура браузерной оболочки ещё не выбрана; React и Unity не добавлены.

Запуск Godot: открыть `project.godot` в указанной версии движка. Web-пресет экспортирует в `build/web/index.html` с оболочкой `web/shell.html`. Отдельные веб-игры собираются своими инструментами; следуйте командам каталога исходников.

На текущей рабочей машине подготовлен portable Godot той же версии (вне репозитория). Открыть редактор:

```bash
"$HOME/.local/share/godot-bin/4.7.2/Godot_v4.7.2-stable_linux.x86_64" --editor --path .
```
