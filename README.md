# LATENTPUNK: TEST SUBJECT 0

**«Мы тестируем реальность. Реальность тестирует вас».**

Научно-фантастический психологический хоррор о тестировщике LATENT SYSTEMS. Озвученное вступление продолжается тремя рабочими днями: примитивная проба, выбор симуляций на рабочем компьютере, опросы с последствиями, возвращение домой и физическая аварийная последовательность с тремя финальными исходами.

Проект для Гейм джема Цифрового колледжа **«72 часа»**, 9–12 октября 2026, тема **`****-ПАНК`**. Первая цель — цельный атмосферный игровой цикл. Конкретные механики и количество миров могут измениться.

## Состояние

- Сохранён технический шаблон Godot 4.7.2 Standard, GDScript, Compatibility, однопоточный Web-экспорт; стартовая сцена — `scenes/start.tscn`.
- После «Играть» запускается озвученный пролог: пользовательский логотип, фон `#141413`, субтитры Open Runde с накоплением абзацев и плавный переход в уже загруженный город. Любое нажатие проявляет подсказку; удержание Enter 1,2 с пропускает вступление. Последняя реплика об адресе проигрывается отдельной сухой записью без эффектов. Исходный MP3 удалён по просьбе участника после проверки; обработка, происхождение и таймкоды — в `assets/audio/prologue/provenance.json`.
- Реализовано спокойное вступление от городской остановки до кабинета 1406: населённый квартал, холл, администратор, лифт и собеседование LATENT SYSTEMS с десятью вопросами и двумя заданиями. Управление — WASD, мышь, E; Esc — пауза, повторный запуск и меню. Устройство сцены, экспорт и проверки описаны в [paper/PIPELINES.md](paper/PIPELINES.md#вступление-latentpunk).
- Подключены 31 синтетическая реплика NPC/терминала и 5 записанных участником реплик героя: автобус, ресепшен, попытка вызвать лифт до разговора с администратором и неправильный этаж. Автоматические переходы ждут окончания записи; пауза/потеря фокуса приостанавливают речь, mute не останавливает диалог, ручной пропуск остаётся доступен. Записанный пролог сохранён. Происхождение — [assets/SOURCES.md](assets/SOURCES.md#синтетические-голоса-персонажей).
- Для города и интерьеров выбран белый графичный ретро-стиль с акцентами `#AC2954` / `#5B4CFF`, тёмным асфальтом, лиловым окружением и toon-освещением; NPC используют тот же стиль. Геометрия и игровой маршрут сохранены.
- В `games/` собраны исходные проекты и готовые сборки независимых браузерных игр. Их тип поставки, происхождение, лицензии и команды запуска — в [paper/SOURCES.md](paper/SOURCES.md). Существующие исходники сохранены; для новых импортов достаточно работающей сборки.
- Реализованы испытательный этаж, физическая калибровка, квартира с вечерними записями и переходом к утру, служебный сектор, эвакуация и Game Over с повтором только аварийного участка. Фактический сюжет и локации — [paper/CAMPAIGN_IMPLEMENTATION.md](paper/CAMPAIGN_IMPLEMENTATION.md).
- В каталоге 18 стендов: собственная калибровка и 17 включённых веб-игр. В Web игры открываются в iframe поверх Godot; в настольной версии — внутри того же окна через Godot CEF. После «Завершить тестирование» появляется опрос; победа оригинальной игры не требуется. Существующие JS/CSS chunks не переписаны.
- Подключена 21 новая реплика Ники, Артёма и Елены через Fish Speech S2-Pro с постоянными референсами: [тексты и ID](paper/VOICE_SUPPORTING.md), [плейлист](assets/audio/dialogue/campaign/playlist.m3u), [происхождение](assets/SOURCES.md#голоса-продолжения). 14 реплик [ГГ продолжения](paper/VOICE_HERO.md) пока текстовые. Существующее записанное вступление и голоса сохранены.

Запуск Godot: открыть `project.godot` в указанной версии движка. Перед первым настольным запуском выполнить `python3 .github/scripts/prepare_cef.py`, затем перезапустить Godot. Перед запуском симуляций выполнить `python3 .github/scripts/prepare_modules.py` — он собирает два собственных проекта и готовит `build/campaign-modules/`. Нужны Node.js 22/npm и Python; игрокам готовой настольной сборки они не нужны. Установщик скачивает закреплённый Godot CEF 2.0.0, проверяет SHA-256 и сохраняет нативные библиотеки в игнорируемом `addons/godot_cef/`. Упаковщик выполняет оба шага автоматически. Один экспорт Godot без каталога модулей не содержит независимые игры.

На текущей рабочей машине подготовлен portable Godot той же версии (вне репозитория). Открыть редактор:

```bash
"$HOME/.local/share/godot-bin/4.7.2/Godot_v4.7.2-stable_linux.x86_64" --editor --path .
```

## Альфа-релизы

Версия проекта — `0.2.0-alpha`. После push в `main` workflow `.github/workflows/release.yml` собирает четыре архива и публикует GitHub **prerelease `v0.2.0-alpha`**: Linux x86_64, Windows x86_64, macOS universal и полный однопоточный Web-экспорт. Релиз публикуется только после всех экспортов и проверок; в архивы включены инструкции и notices, рядом — `SHA256SUMS`.

Готовый релиз не перезаписывается следующим push с той же версией. Для следующего релиза изменить `config/version` в `project.godot`, обновить числовую версию macOS в `export_presets.cfg` и [заметки релиза](paper/RELEASE_NOTES.md). Если черновик или тег уже закреплён за другим коммитом, workflow потребует новую версию, а не подменит старую сборку. Повтор упавшего workflow на том же коммите допускается.

GitHub Actions использует автоматический `GITHUB_TOKEN`; отдельный пользовательский токен или ручное создание тега не нужны. Workflow имеет право записи только в job публикации. Настройки репозитория должны разрешать запуск Actions и создание релизов.

Локальный экспорт использует те же пресеты и упаковщик. Нужны Godot 4.7.2 Standard, Python 3.11+, Node.js 22/npm и экспортные шаблоны Linux/Windows/macOS/Web той же версии:

```bash
python3 .github/scripts/export_release.py --godot "$HOME/.local/share/godot-bin/4.7.2/Godot_v4.7.2-stable_linux.x86_64"
```

Архивы появятся в `build/release/0.2.0-alpha/`. Web распаковать и обслуживать по HTTP, например `python3 -m http.server 8060` из каталога распакованной сборки. macOS alpha не подписана и не нотарифицирована; Gatekeeper может потребовать разрешения в настройках безопасности. Windows EXE также не подписан. Наличие экспортов не означает проверенное прохождение на Windows/macOS.
